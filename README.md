## Product specification

**Target customer:** Self-managing landlords with 2–15 units who handle tenant communication themselves without a property manager

### Core MVP features
- Tenant directory with lease dates, rent amount, and contact info per unit
- Automated rent reminder sequence: SMS/email on day -3, day 0, day +3 of due date
- Maintenance request intake form (tenant-facing link); AI drafts landlord acknowledgment and estimated timeline reply
- Lease renewal alert 90/60/30 days before expiry with AI-drafted renewal offer letter
- Monthly landlord summary: who paid, who is late, open maintenance tickets

**Pricing:** Per-unit monthly subscription at $5/unit/mo (minimum $15/mo), capped at $79/mo for 20+ units

**Go-to-market:** r/landlord, r/realestateinvesting, local real estate investor meetup groups, SEO targeting 'rent reminder automation landlord'

**Competitive landscape:** Buildium and AppFolio do this but cost $250+/mo and require full platform adoption; TurboTenant is free but has no AI communication automation

**Agentic automation plan:** Cron agent runs daily: checks rent due dates and sends reminders automatically; processes maintenance intake form submissions and drafts replies; triggers lease renewal sequences — landlord only approves edge cases flagged by confidence scoring

**MVP estimate:** Next.js + Supabase + Twilio for SMS + SendGrid for email + self-hosted Mistral for message drafting; 3 weeks to MVP
